# نماذج امتحانات — المعلمة إشراق الخروبي

موقع ثابت (HTML/CSS/JS) لتحميل نماذج الامتحانات، منشور على GitHub Pages.

## إضافة صف أو مادة جديدة
1. ضع ملفات PDF في مجلد جديد مثل `files/grade11/english/midterm/`.
2. ضع صور الأغلفة (webp + jpg بعرض 600px) في `assets/img/covers/`.
3. أضف كتلة جديدة في `assets/js/catalog.js` داخل `COLLECTIONS`.

أزرار التصفية حسب الصف والمادة تظهر تلقائيًا عند وجود أكثر من مجموعة.
مفتاح الإجابات غير منشور على الموقع.
